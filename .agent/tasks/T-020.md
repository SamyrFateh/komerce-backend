# T-020 — D8 — Grille desktop 60/1fr/310 puis 64/1fr/340

- Feature ID : `modal-product`

## Objectif

Aligner les proportions desktop sans casser le cliquet render-static.

## Périmètre autorisé

- `public/boutique/css/modal-product-lot4-hybrid.css` — seul propriétaire de
  `grid-template-columns`, `gap`, `padding` de `.k-modal-product-zone`.
- `public/boutique/css/modal-shell.css` — extension approuvée (arbitrage T-020) :
  uniquement placement des enfants (`grid-column`/`grid-row`) de
  `.k-modal-product-zone`, retrait de l'override concurrent `grid-template-columns`
  du bloc `900px–1120px`, mise à jour des commentaires d'ownership.
- `public/boutique/index.html` — extension approuvée : uniquement correction du
  commentaire obsolète « 2 colonnes ». Aucun changement de markup.
- `.agent/evidence/T-020/**`

## Modèle structurel (≥1024px)

Trois pistes : rail miniatures (60/64px) | média principal (minmax) | détails
(310/340px). `.k-modal-thumbs` reste imbriqué en absolu dans `.k-modal-img-wrap`,
qui doit donc couvrir les deux premières pistes.

```css
.k-modal-img-wrap { grid-column: 1 / 3; grid-row: 1 / 3; }
.k-modal-details  { grid-column: 3;     grid-row: 1; }
.k-modal-actions  { grid-column: 3;     grid-row: 2; }
```

Comportement 900–1023px inchangé (2 colonnes).

## Périmètre interdit

- `display:grid`
- `Gate render-static`

## Action attendue

1. Définir 60px minmax(420px,1fr) 310px à 1024–1439.
2. Définir 64px minmax(480px,1fr) 340px à partir de 1440.
3. Appliquer gaps et paddings 18/22 px.
4. Tester large ≥1600.
