## Extension de périmètre — Option D (complète)

Le périmètre initial (frontend uniquement) s'est révélé insuffisant : `product.series`
n'existait pas encore côté contrat backend. L'Option D a donc étendu la tâche de bout
en bout :

- ajout de la colonne nullable `products.series` (migration `112_add_series_to_products.sql`) ;
- extension du schéma `schemas/catalog/product-detail.v1.schema.json` ;
- mapping dans `services/catalog-product-detail.js` (série non nulle, fallback `null` silencieux) ;
- mise à jour de `tests/unit/catalog-product-detail.test.js` pour verrouiller le contrat backend ;
- alignement du test golden `tests/unit/golden-product-gpm1.test.js` sur `series: null`
  (décision reviewer : le champ reste dans le service, c'est le golden qui était obsolète) ;
- mise à jour de `docs/doctrine/DOCTRINE_PRODUCT_DETAIL_CONTRACT.md` (v1.2) pour documenter
  `product.series` dans le contrat public.
