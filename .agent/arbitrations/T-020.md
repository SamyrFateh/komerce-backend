# ARBITRAGE — T-020

## Décision attendue
T-020 (grille 3 pistes desktop) autorise uniquement modal-product-lot4-hybrid.css. Le placement des enfants (grid-column/grid-row de .k-modal-img-wrap et .k-modal-details) est owned par modal-shell.css, hors périmètre. Comment procéder ?

## Faits
Vérifié dans le code réel : #k-modal-product-zone en 900px a grid-column:1;grid-row:1/3 sur .k-modal-img-wrap et grid-column:2;grid-row:1 sur .k-modal-details, déclarés dans modal-shell.css. T-020 n'autorisait initialement que modal-product-lot4-hybrid.css.

## Options
1. Étendre le périmètre T-020 à modal-shell.css pour déplacer le placement des enfants (rail, média, détails), un seul propriétaire par propriété.
2. Ajouter des overrides grid-column plus spécifiques dans modal-product-lot4-hybrid.css sans toucher modal-shell.css (dépend de l'ordre du bundle, deux propriétaires concurrents).

## Recommandation
Étendre le périmètre à modal-shell.css : évite un ownership dupliqué et une dépendance fragile à l'ordre de cascade, conforme à la doctrine zéro dette technique.

## Décision

Option 1 retenue par le porteur du projet : extension du périmètre à
`modal-shell.css` et `index.html` (commentaire uniquement). Option 2 écartée :
dépendrait de l'ordre du bundle, deux propriétaires concurrents pour
`grid-column`.

## Modèle structurel retenu

À partir de 1024px, `.k-modal-product-zone` : rail miniatures (60/64px) | média
principal (minmax) | détails (310/340px).

```css
.k-modal-img-wrap { grid-column: 1 / 3; grid-row: 1 / 3; }
.k-modal-details  { grid-column: 3;     grid-row: 1; }
.k-modal-actions  { grid-column: 3;     grid-row: 2; }
```

`.k-modal-img-wrap` couvre les deux premières pistes car `.k-modal-thumbs` reste
imbriqué en position absolue dedans. Comportement 900–1023px inchangé.

## Ownership post-arbitrage

- `modal-product-lot4-hybrid.css` : `grid-template-columns`, `gap`, `padding` de
  `.k-modal-product-zone`.
- `modal-shell.css` : `grid-column`/`grid-row` des enfants, confinement de la
  product-zone, scroll interne des détails, placement sticky des actions.

## Nettoyage obligatoire

Retrait de la déclaration concurrente `grid-template-columns` sur
`.k-modal-product-zone` dans le bloc `@media (min-width: 900px) and
(max-width: 1120px)` de `modal-shell.css`.

## Hors périmètre (rappel)

Style visuel des miniatures → T-021. Aucun changement de markup dans `index.html`.
