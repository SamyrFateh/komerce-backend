# Arbitrage T-023 — Extension de périmètre à modal-product.css

## Contexte

`css-guard` identifie `public/boutique/css/modal-product.css` comme source
réellement concurrente de `public/boutique/css/modal-product-lot4-hybrid.css`
sur le sélecteur `#k-modal-payment` (layout desktop, ≥900px) :

- `modal-product.css:1225` → `#k-modal-payment.k-modal-payment`
- `modal-product-lot4-hybrid.css:71-72` → `#k-modal .k-modal-payment`

Spécificité identique (0,1,1,0) des deux côtés : le gagnant dépend de l'ordre
de chargement du bundle, ce qui constitue le conflit signalé par css-guard.
`modal-product.css` était hors périmètre initial de T-023.

## Décision

Extension du périmètre autorisé de T-023 à `modal-product.css`, strictement
limitée à la réconciliation de la règle desktop de `#k-modal-payment`, sur
les propriétés de layout : `display`, `border-top`, `margin-top` (et
`width`/`padding` uniquement si nécessaire à la consolidation).

Propriétaire unique retenu : `modal-product-lot4-hybrid.css` (déjà dans le
périmètre initial, porteur du bloc combiné "Livraison + paiement" cohérent
avec l'objectif D11). La déclaration concurrente dans `modal-product.css`
est supprimée, sans ajout d'un troisième override.
