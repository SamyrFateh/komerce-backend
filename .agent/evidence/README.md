# Preuves

Chaque tâche dispose de son propre sous-dossier.

Convention recommandée :

```text
T-001/
├── before.png
├── after.png
├── tests.txt
├── commands.txt
├── diff-summary.txt
└── reviewer-notes.md
```

Ne pas déposer de secrets, mots de passe, jetons ou données personnelles dans les preuves.
