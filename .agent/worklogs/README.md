# Worklogs de reprise

Chaque tâche active possède `.agent/worklogs/T-XXX.md`, créé et alimenté automatiquement par `scripts/agent.mjs` à chaque démarrage, checkpoint, reprise, fin, blocage ou arbitrage.

Le worklog donne au prochain agent le dernier résultat et la prochaine action exacte. Les commits restent la preuve du code sauvegardé.
