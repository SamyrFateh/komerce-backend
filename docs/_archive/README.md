- un document archivé peut servir à comprendre l'histoire ;
- il ne doit jamais être utilisé comme source de vérité opératoire ;
- si une information archivée redevient nécessaire, elle doit être copiée dans un document actif listé par `docs/README.md` ;
- toute ancienne documentation V4.1, collective workspace, cagnotte, engagement ou financement collectif est subordonnée à la doctrine Boutique First.
