# Recette navigateur Catalogue × Pricing

La preuve API authentifiée et les captures Chromium simulées ne suffisent pas à établir qu'un opérateur peut effectuer la correction dans le navigateur sur Railway. Les conditions GO sont : une session fictive authentifiée, un dossier Sourcing synthétique, une catégorie économique validée dans le panneau Catalogue, un nouveau calcul du coût variable et du plancher, aucune publication, et une ouverture de l'Atelier des prix. Aucun identifiant ne doit être placé dans le dépôt.
